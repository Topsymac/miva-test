# Miva Student Information Management System

This is a simple **Student Information Management System** built with **Next.js**, **TypeScript**, **Tailwind CSS**, and **Chakra UI**. It allows administrators to manage student records including viewing, editing, and deleting student data.

---

## 🛠 Tech Stack

- **Framework:** Next.js (App Router & Pages Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS + Chakra UI
- **API:** Next.js API routes (mocked data)
- **State Management:** React Context
- **Data Fetching:**  REST API
